## 🚀 How to Deploy on Vercel in 60 Seconds

You already have `vercel.cmd` installed on your machine!

### Method A: One-Command Terminal Deploy
1. Open PowerShell or Command Prompt in this folder (`c:\Users\krish\Downloads\NANDU`).
2. Run:
   ```bash
   vercel.cmd --prod
   ```
3. Follow the quick prompts. Vercel will give you a live production URL like `https://nanduu-love-universe.vercel.app`!

### Method B: Vercel Web Dashboard (Drag & Drop or GitHub)
1. Go to [vercel.com/new](https://vercel.com/new).
2. Connect your GitHub repository or drag and drop this folder.
3. Click **Deploy**! It's pre-configured with `vercel.json` for zero-configuration instant deployment.
